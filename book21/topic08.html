🌱 成功的相反，
是什麼？

如果一次沒有達標就叫失敗，那幾乎所有真正重要的成長，都會在過程中被判成失敗。

本單元主軸
科展 → 未達目標 → 重新定義失敗 → 行動 → 累積 → 成長

🔬 科展的故事

一場科展原本期待得到好成績，結果卻沒有如願。表面上看像是失敗，但準備、嘗試與反覆修正的過程，其實已經留下很多能力。

🎯 目標未達就是失敗？

如果把成功只定義成「達成預期結果」，那沒有拿獎、沒有錄取、沒有升遷，都很容易被貼上失敗標籤。
但結果只是其中一個指標，過程中的學習、方法與判斷力也會累積。

🔄 重新定義失敗

失敗不一定是「沒有得到想要的結果」，也可以理解成：一次實驗沒有得到原先假設的答案，卻提供了下一次行動的新資訊。

⛔ 比失敗更糟的是什麼？

真正讓人成長停住的，往往不是做錯，而是不做。沒有嘗試，就沒有回饋；沒有回饋，也就沒有修正的可能。

🏃 行動才會有結果

行動不保證成功。
但不行動幾乎保證沒有新的結果。

所以重點不是消除失敗，而是讓每次行動都能產生資訊。

💭 夢想要配行動

夢想本身不會累積能力。真正形成差距的是：把想法變成一次次可以測試、修正、再前進的行動。

🧪 失敗是必經之路

只要事情具有挑戰性，就不可能每次都成功。把失敗視為例外，會讓人逃避嘗試；把它視為學習流程的一部分，反而比較能持續。

📚 每次失敗，都是累積

累積判斷：知道什麼行不通。
累積方法：知道下次怎麼改。
累積韌性：知道自己承受得住。
累積證據：知道哪些能力真的提升了。

✨ 你不是 0 分

一次結果不理想，不代表之前的努力歸零。真正值得追蹤的，是你有沒有比上一次更知道自己在做什麼。

結語：成功的相反，不一定是失敗；更可能是停止行動、停止學習、停止累積。
